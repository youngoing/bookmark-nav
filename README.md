# bookmark-nav

`bookmark-nav` 是一个自托管书签导航工具，用于集中保存、整理、检索和访问个人书签。

## 核心功能

- 书签导航主页：以网格、列表、表格等方式展示书签，支持快速打开链接。
- 目录管理：按目录整理书签，主页可按目录筛选。
- 标签管理：支持标签和子标签，用于多维度归类书签。
- 网站分组：同一网站下的多个子链接可聚合展示。
- 收藏与最近添加：支持收藏常用书签，并快速查看最近保存的内容。
- 关键词搜索：可按标题、域名、描述等信息查找书签。
- 点击统计：记录书签访问次数，便于识别高频资源。

## 管理后台

后台页面 `/edit` 用于配置和维护数据：

- 书签管理：新增、编辑、删除、收藏、分享书签。
- 目录管理：创建和编辑目录。
- 标签管理：创建、编辑、删除标签，并可发布标签合集。
- 网站管理：维护网站信息，并为网站添加子链接。
- 分享管理：查看公开分享内容，并保存到个人空间。
- 通用查询：支持展示字段和表结构字段查询，支持 AND/OR 条件组合与分页。

## 账号与登录

- 支持 Google OAuth 登录，并可通过配置启用飞书开放平台用户授权登录。
- 支持账号密码登录。
- 支持账号基础信息和密码管理。

## 浏览器扩展

项目提供 Chrome 扩展，用于一键保存当前页面：

- 通过用户 API Key 连接个人工作区。
- 自动读取当前页面标题、URL、描述和 favicon。
- 保存时可选择目录和标签。
- 网页端提供扩展下载入口。

## 分享能力

- 单条书签可发布为公开分享。
- 标签下的书签可发布为共享合集。
- 发现页可浏览并保存他人公开分享内容。
